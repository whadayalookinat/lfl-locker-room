# Loser's Locker Room

Member-facing 2026 Locker Room for the Loser Football League.

- **Members:** https://whadayalookinat.github.io/lfl-locker-room/
- **Commissioner console:** https://whadayalookinat.github.io/lfl-locker-room/commissioner.html
- **League standings and results:** https://whadayalookinat.github.io/lfl-site/

The member homepage supports username/password login, season team identification, and weekly comments. The commissioner console manages participant profiles, team assignments, passwords, and new accounts. Authentication and member data are managed in Supabase; the public GitHub Pages files do not contain credentials. Passwords must be at least 12 characters. There is no public self-registration.

Earlier pilot and QA pages remain in the repository for reference. The release entry points above are the URLs to share. Automated LFL standings publication is maintained separately in the `whadayalookinat/LFL` repository.
